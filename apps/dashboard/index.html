프로젝트 단체방 설정

한 프로젝트는 사용자, superior(최상위 조정자), 최대 4명의 LLM 멤버가 하나의 단체방에서 순서대로 대화합니다. 매 라운드마다 superior가 짧은 계획을 만들고, 멤버 보고를 취합해 최종 답변을 작성합니다. 멤버는 파일을 변경하지 않습니다.

superior · 최상위 조정자

사용자 바로 아래 권한의 프로젝트 대표입니다. 프로젝트의 최종 답변과 라운드 계획을 담당합니다.

1~50은 지정한 횟수만큼 같은 멤버 순서를 다시 돌며 보완합니다. 재시도는 빈 응답 또는 일시적인 연결 실패에만 적용되고, 시간 초과·사용자 중지는 재시도하지 않습니다.

실험 기능: 라운드 0은 superior가 완료를 판단할 때까지 반복합니다. 종료 판단이 없으면 무한 루프가 될 수 있어, FLUX가 50라운드에서 자동 비상 정지합니다.

멤버 · 최대 4명

응답 완료 제한은 이 멤버가 한 차례의 보고를 끝낼 수 있는 최대 시간입니다. 다음 멤버 시작 전 간격은 이 멤버의 보고가 끝난 뒤 다음 순번을 호출하기 전까지 기다리는 시간입니다.

말투·행동 설정

웹과 Discord 대화에 공통 적용합니다. 현재 요청, 프로젝트 지침, 승인·보안 규칙보다 우선하지 않습니다.

제목·목록·표·언어가 표시된 코드 블록을 읽기 쉬울 때 사용하도록 모델에 요청합니다. 짧은 답변에 억지로 서식을 넣지는 않습니다.

승인 요청

파일 변경·삭제 등은 여기에서 직접 검토하고 승인해야 실행됩니다.

즉시 지시

현재 모델 호출을 자동 취소하고 이 지시를 최우선으로 반영해 다시 시작합니다. 아직 승인되지 않은 이 대화의 파일 변경 요청은 만료됩니다.

파일 작업 승인 정책

출처 기록은 항상 FLUX 내부에 남습니다. 이 옵션은 주석을 지원하는 텍스트 코드 파일에만 적용되며, 기존 파일을 사람이 수정한 뒤의 현재 작성자를 보증하지 않습니다.

삭제는 어떤 정책에서도 대상 경로를 직접 확인한 뒤에만 실행합니다. 프로젝트 밖·운영체제 핵심 경로는 항상 차단됩니다.
