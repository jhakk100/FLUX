# 프로젝트 단체방 사용법

프로젝트에는 사용자, superior, 최대 4명의 멤버가 하나의 대화방에 함께 참여합니다.

## 시작하기

1. 프로젝트 대화를 연 뒤 상단의 멤버 버튼을 누릅니다.
2. superior 영역에서 최종 답변을 만들 조정자 모델을 고릅니다. 비워두면 설정 화면의 기본 AI API와 모델을 사용합니다.
3. 멤버별로 이름, 역할, API, 모델, 발언 순서를 저장합니다.
4. 협업 라운드와 빈 응답 자동 재시도 횟수를 저장합니다.
5. 프로젝트 대화에 메시지를 보내면 superior와 활성 멤버가 순서대로 대화합니다.

## 시간 설정

- 응답 완료 제한: 한 멤버가 한 번의 보고를 마칠 수 있는 최대 시간입니다. 1~300초 범위입니다.
- 다음 멤버 시작 전 간격: 이 멤버의 보고가 끝난 뒤 다음 멤버를 부르기까지 기다리는 시간입니다. 0~300초 범위입니다.
- 로컬 모델이 포함된 경우에는 각 모델의 응답 시간을 고려해 충분한 제한 시간을 권장합니다.

## 라운드와 재시도

- 라운드는 superior의 계획과 멤버 순서를 다시 돌며 답을 보완하는 횟수입니다. 1~3회만 설정할 수 있어 무한 반복하지 않습니다.
- 빈 답변이나 일시적 연결 실패는 0~2회 다시 시도합니다.
- 시간 초과와 사용자가 누른 중지는 자동 재시도하지 않습니다.
- 실행 중 화면과 단체방 기록에서 누가 어떤 라운드에 참여했는지, 몇 번 시도했는지, 실패 원인을 확인할 수 있습니다.

멤버는 분석·검토 전용입니다. 파일 생성·수정·삭제와 승인 판단은 최종 superior 응답의 기존 승인 정책을 통해서만 진행됩니다.
