- [ ] **1.0 이전 필수 — 독립 FLUX 서비스 수명 관리**
  - Gateway는 일반 CLI 명령을 실행한 터미널에 묶이지 않는 사용자당 단일 서비스로 실행한다.
  - flux CLI와 웹 대시보드는 이미 실행 중인 서비스를 재사용하며, 단발 명령 종료가 Gateway를 멈추거나 새 배너·새 프로세스를 남기지 않는다.
  - flux start, flux status, flux stop으로 수명을 명시적으로 관리하고, PID·잠금·상태 기록으로 중복 실행과 오래된 서비스 기록을 복구한다.
  - 대화형 서비스 콘솔에서는 첫 Ctrl+C로 종료 의사를 알리고, 짧은 시간 안의 두 번째 Ctrl+C에서만 정상 종료한다.
  - 시작 배너는 대화형 서비스 시작 시에만 한 번 표시하고, 상태·API 등 비대화형 CLI 출력은 조용하고 구조화된 결과를 유지한다.
- [x] 빌드 후 FLUX 관련 고아 Node 프로세스 검사
- [ ] **CLI LLM 서비스 센터 (flux ask)**
  - Ollama에 설치한 gemma4:e2b급 소형 로컬 모델을 기본 안내 모델로 사용하며, 외부 API 키나 사용량을 자동으로 소비하지 않는다.
  - 등록된 FLUX 명령 카탈로그·설명·예시만 문맥으로 제공하고, LLM은 명령을 자동 실행하지 않는다.
  - 카탈로그에 없는 기능·질문에는 추측하지 않고 등록되지 않은 질문 또는 아직 지원하지 않는 기능이라고 명확히 답한다.
  - 자주 쓰는 설치·상태·프로젝트·API·문제 진단 명령을 확장하고, 각 명령의 도움말과 서비스 센터 안내를 같은 카탈로그에서 관리한다.
- [ ] CLI 출력 모드: 대화형 세션에서만 시작 배너·한 줄 안내를 표시하고, 상태·API 등 비대화형 명령은 조용한 구조화 출력 유지
- [ ] **1.0 이전 필수 — 한국어/영어 UI·CLI 지원**
  - 대시보드와 CLI의 고정 문구를 언어 리소스로 분리하고, 사용자 설정에서 한국어·영어를 전환한다.
