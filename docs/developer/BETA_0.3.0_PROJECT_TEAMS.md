# 0.3.0 베타 — 프로젝트 작업 공간과 에이전트 팀

## 목표

프로젝트는 단순한 폴더 연결이 아니라 대화와 에이전트 팀을 담는 작업 공간이다. 일반 대화는 어느 프로젝트에도 속하지 않는 빠른 대화로 유지한다.

```text
일반 대화
  - 독립 대화

프로젝트
  - 프로젝트 대화
  - 에이전트 팀
```

## 사용자 흐름

1. 사용자는 프로젝트에 역할별 에이전트를 등록한다. 에이전트는 이미 설정된 공급자와 모델을 참조한다.
2. 프로젝트 대화에서만 `협업 실행`을 명시적으로 선택할 수 있다.
3. 작업자 에이전트는 같은 사용자 요청을 병렬로 분석한다.
4. 리더 모델은 작업자 결과를 참고해 하나의 최종 답변을 작성한다.
5. 파일 변경은 어느 에이전트가 제안하더라도 기존 FLUX 승인 정책을 거친다.

## 안전·비용 규칙

- 협업은 기본적으로 꺼져 있다. 일반 메시지는 현재처럼 한 모델만 사용한다.
- 작업자 에이전트는 분석 전용이다. 작업자 응답의 파일 도구 호출은 실행하지 않는다.
- API 키는 에이전트 프로필에 복사하지 않는다. 기존 로컬 공급자 설정을 재사용한다.
- 작업자 오류는 다른 작업자를 중단시키지 않으며, 최종 리더에게 오류 상태로 전달한다.
- 프로젝트 삭제는 실제 작업 폴더·대화를 삭제하지 않는 현재 정책을 유지한다.
