## FLUX-KI-001 — Ollama Gemma 4가 이미지 첨부에 빈 답변을 반환함

| 항목 | 내용 |
| --- | --- |
| 상태 | **재현됨 · 외부 의존성** |
| 영향 범위 | Ollama의 `gemma4:e2b`, `gemma4:e4b`로 이미지 첨부 대화를 보낼 때 |
| 증상 | Ollama가 HTTP 200으로 요청을 완료하지만 최종 답변인 `message.content`가 비어 있어 답변이 생성되지 않음 |
| 데이터 영향 | 없음. 첨부 파일과 대화 기록은 보존됨 |
| FLUX 처리 | 빈 답변을 저장하지 않고, 응답 생성 실패 원인을 대화에 표시함 |

### 원인

FLUX가 사용하는 표준 Ollama `/api/chat` 이미지 요청은 서버까지 정상 도달합니다. 문제는 Ollama/Gemma 4가 일부 비전 요청에서 최종 답변 없이 완료되는 동작입니다. Gemma 4의 thinking 출력이 생성 토큰 예산을 모두 사용해 `content`가 비는 유사 사례가 Ollama에 보고되어 있습니다. [Ollama 이슈 #16184](https://github.com/ollama/ollama/issues/16184)
